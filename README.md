# 小日子

## 现在可以使用的功能

- 喝水、大便、小便记录
- 生理期开始、持续天数、每日经量与疼痛、结束日期和历史补记
- 与经期分开的普通疼痛记录
- 本机保存、日历回看、趋势统计
- JSON 数据导出与导入

## 本地预览

打开 `index.html` 即可使用。记录会保存在当前浏览器内，请勿使用无痕模式，并建议定期在“设置与数据”里导出备份。

## 安装到 iPhone

需要先把整个文件夹发布到一个 HTTPS 网站，随后用 iPhone 的 Safari 打开网址，点击“分享”→“添加到主屏幕”。通过 HTTPS 打开后，应用会缓存基础文件用于离线访问。

## 隐私提示

当前版本没有服务器，不会自动上传健康记录。清理浏览器数据可能同时删除记录，因此换设备或清理浏览器前请先导出备份。
